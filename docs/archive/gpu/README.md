# GPU development evidence archive

These are historical reports from 25–27 October 2026. Statements about current
or future work describe the revision tested at that time. Begin with the
[current GPU guide](../../gpu/README.md) for present capabilities and limitations.

Reports and evidence were moved together without changing their bytes. Recorded
commits, hashes and original runtime paths remain historical provenance. Large
raw runs and frozen binaries remain in ignored local storage; these reports do
not promise those local artifacts exist in every checkout.

The [previous overview](overview_before_consolidation_2026_10_27.md) preserves
the guide before consolidation, including its historical interface and commands.
For current interface and commands, use the [architecture guide](../../gpu/architecture.md).
