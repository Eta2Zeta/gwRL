# M12: learning and operational gate

**Completed milestone reference, 23 October 2026.** For current progress use the
[project guide](../README.md); for measured training outcomes use
[learning status](../stage_a/README.md). Current commands live in the
[campaign workflow](../../studies/campaign/README.md).

M12 delivered entity-graph policy/value networks, batched stochastic search,
resumable parallel self-play, held-out evaluation and profiling. Exact continuation
checks covered populated optimizer state, replay, active games, scheduling and all
random generators. The operational smoke included truncated learned-policy games
and completed scripted controls; it did not demonstrate playing strength.

The [original delivery report](../archive/milestones/m12/overview_2026_10_23.md)
and [milestone evidence index](../archive/milestones/README.md) preserve the original
measurements, configurations and JSON results. Those timings and “next steps”
describe the original runtime and are historical.
